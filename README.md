# 修士論文 LaTeX テンプレート

## 概要

これは、修士論文執筆用のLaTeXテンプレートです。論文の構造と体裁を整えるための設定が組み込まれており、修論の執筆に集中できるよう設計されています。

**【重要】**
**このテンプレートは、R5年度提出時の工学研究科指定様式に基づいて作成しています。** 各年度、様式が変更される可能性があるため、必ず最新の公式要綱を確認してください。

## 特徴

*   **uplatex + dvipdfmx** を使用した日本語環境に対応
*   参考文献管理には **biblatex + biber** を採用し、引用順に自動で番号を振ります
*   **章ごとのファイル分割**により、長文でも管理しやすい構成
*   図表や式の参照を簡単にするための**カスタムコマンド**を整備
*   `latexmk`による自動ビルド設定済み（出力ファイルは`out/`ディレクトリに生成）

## ディレクトリ構造

```
.
├── .gitattributes      # Gitの改行コード・バイナリファイル設定
├── .gitignore          # Gitの追跡対象外ファイルを設定
├── .latexmkrc          # latexmkのビルド設定
├── backmatter/         # 論文の後付け部分
│   ├── acknowledgment.tex # 謝辞
│   ├── appendixA.tex      # 付録A
│   ├── appendixB.tex      # 付録B
│   └── references.bib     # 参考文献データベース
├── chapters/           # 各章の本文
│   ├── chap1.tex
│   ├── chap2.tex
│   ├── chap3.tex
│   ├── chap4.tex
│   └── chap5.tex
├── figures/            # 図・画像ファイル
│   ├── chap1/
│   ├── chap2/
│   ├── ...
├── main.tex            # 全体を統括するメインファイル（コンパイル対象）
├── preamble/           # プリアンブル（共通マクロ定義など）
│   └── macros.tex
└── styles/             # スタイル・クラスファイル
    ├── thesis-cite.cbx     # 引用スタイル（上付き数字）
    ├── thesis-numeric.bbx  # 参考文献リストのスタイル
    ├── thesis-packages.sty # 共通パッケージの読み込み
    └── thesis.cls          # 論文全体のレイアウト定義
```

## 各ファイル・ディレクトリの役割

### 1. 論文の執筆

論文の本文は、主に以下のファイルを編集します。

*   `main.tex`
    *   論文全体の構造を定義するファイルです。**全体をコンパイルする際はこのファイルに対して行います。**
    *   章のタイトル変更や、章の追加・削除はここで行います。
*   `chapters/`
    *   各章の本文を記述するファイルが格納されています。`chap1.tex`が第1章、`chap2.tex`が第2章に対応します。
    *   章ごとにファイルが分かれているため、編集・管理が容易で、添削時用などに章ごとの単体コンパイルも可能です。
*   `backmatter/`
    *   `references.bib`: 参考文献の情報をBibTeX形式で記述します。論文サイトの「Export BibTeX」機能などを使って情報を追加してください。（詳細は `chapters/chap2.tex` に記載）
    *   `acknowledgment.tex`: 謝辞を記述します。
    *   `appendixA.tex`, `appendixB.tex`: 付録を記述します。
*   `figures/`
    *   論文で使用する図（画像ファイル）を格納します。
    *   `figures/chap1/` のように、章ごとにサブディレクトリを作成して管理することを推奨します。
    *   原則：**PDF（ベクタ）推奨**、写真は高解像度PNG。ファイル名は英小文字＋ハイフン。
*   `styles/thesis-packages.sty`
    *   パッケージ管理ファイルです。`main.tex`, `chapN.tex`どちらのファイルにも適用されます。新たなパッケージが必要になった場合、このファイルに追加してください。
*   `styles/thesis.cls`
    *   工学研究科の学生は、11月あたりに教務から通知がある論文様式を確認し、変更の必要があれば、このファイルを修正してください。
    *   余白・綴じ代は `\RequirePackage[dvipdfmx]{geometry}` 直下の
        ```tex
        \geometry{
            top=26mm, bottom=25mm,
            inner=20mm, outer=20mm,
            heightrounded
        }
        ```
        を調整してください。
*   `preamble/macros.tex`
    *   図・表・式などを参照するための便利なカスタムコマンド (`\figref{}` など) を定義しています。自分で新たにマクロを組みたい場合はこのファイルに追加してください。


### 2. スタイルと設定

論文の体裁やビルドに関する設定ファイルです。基本的に編集する必要はありません。

*   `styles/`
    *   論文のレイアウト（余白、ヘッダ・フッタ）、引用の見た目などを定義するファイル群です。
*   `.latexmkrc`
    *   LaTeXのビルドツール `latexmk` の設定ファイルです。コンパイル方法や、生成ファイルの出力先 (`out/`ディレクトリ) を指定しています。
*   `.gitignore`, `.gitattributes`
    *   バージョン管理ツールGit用の設定ファイルです。コンパイル時に生成される中間ファイルなどをGitの管理対象から除外します。





## 使い方・セットアップ

**基本的なコンパイル方法や執筆の流れについては、2025年4月22日に実施したLaTeX環境構築勉強会の資料を参照してください。**
このテンプレートは、その勉強会で構築した環境で動作することを確認済みです。

将来このテンプレートを利用する後輩の皆さんも、まずはその資料に目を通し、同様の環境を構築することを推奨します。

ここでは、各自の状況に合わせてこのテンプレートを使い始めるためのセットアップ方法を3パターン紹介します。

### 1. 新規で論文執筆を始める場合（Gitでのバージョン管理）

これから論文執筆を始め、Gitでバージョン管理を行いたい場合は、このリポジトリをクローン（複製）するのが最も簡単で推奨される方法です。

Git Bash（Macユーザーはターミナル）などで、論文を保存したいディレクトリに移動し、以下のコマンドを実行してください。

```bash
# "your-thesis-directory" という名前のフォルダにテンプレートを複製します
git clone <このリポジトリのURL> your-thesis-directory
```

コマンドを実行すると、`your-thesis-directory`というフォルダが作成され、その中にテンプレートの全ファイルが格納されます。

### 2. Gitを使わずに手軽に始めたい場合

バージョン管理は不要で、単にテンプレートのファイル一式が必要な場合は、ZIPファイルとしてダウンロードしてください。

1.  このリポジトリのGitHubページ右上にある緑色の「**<> Code**」ボタンをクリックします。
2.  表示されたメニューから「**Download ZIP**」を選択します。
3.  ダウンロードしたZIPファイルを解凍すれば、テンプレートのファイルがすべて揃います。

### 3. 既存の執筆環境にテンプレートを適用したい場合

すでに自分でGitリポジトリを作成し、少し執筆を進めている場合は、以下の手順でバージョン管理の履歴を維持したまま、このテンプレートのファイルを取り込むことができます。

1.  まず、このテンプレートリポジトリを「Download ZIP」からダウンロードし、解凍します。

2.  あなたが現在作業している論文のディレクトリ（例：`my-thesis/`）に、解凍したテンプレートから以下のファイルとディレクトリを**上書きコピー**します。
    *   `.gitattributes`
    *   `.gitignore`
    *   `.latexmkrc`
    *   `main.tex`
    *   `backmatter/` （ディレクトリごと）
    *   `chapters/` （ディレクトリごと）
    *   `figures/` （ディレクトリごと）
    *   `preamble/` （ディレクトリごと）
    *   `styles/` （ディレクトリごと）

3.  すでに執筆した本文があれば、その内容を`chapters/`内の適切なファイル（`chap1.tex`など）にコピー＆ペーストして移植してください。

4.  最後に、コピーした新しいファイル群をGitの管理対象に追加し、コミットします。
    ```bash
    # ターミナルで自分の論文ディレクトリに移動
    cd my-thesis

    # 変更されたファイルと新しく追加されたファイルをステージング
    git add .

    # コミットを実行
    git commit -m "Apply master thesis template"
    ```

これで、執筆履歴を引き継ぎながら、新しいテンプレートの構成で作業を再開できます。
